# Sling Spot AR（仮称）

景色をカメラ越しに狙い、パチンコのように引いて離すとそのスポットへ飛んで、360°回りながら解説する AR 観光アプリのプロトタイプです。

- 公開URL: https://stonygo.github.io/sling-spot-ar/
- バージョン情報・更新履歴・利用規約・プライバシーポリシー・ライセンス表示: アプリ内「⚙️設定 → このアプリについて」または開始画面下部
